Producing a product typically follows these steps

1. Get a problem to solve
2. Research possible solutions
	1. quick and dirty but verifiable
3. Have clearly defined outlines
	1. this is to set up unit tests early
4. development
	1. creating the implementation
	2. update scope if anything changes
		1. update documentation
		2. unit tests
5. Test
	1. individual parts should hall all scenarios tests
	2. overall run should be tested
6. Creating integration test
	1. this simulates real world production data
7. Feedback from interest groups
