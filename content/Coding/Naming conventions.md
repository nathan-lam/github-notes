# Definition
Different types of naming conventions used for variables, file names, folder names.

# Types

## Camel Case
```
variableName # camel case
VariableName # Pascal case
```

Saves a separator char

## Snake Case
words connected by an underscore
```
variable_name
```



## Kebab Case
Words connected by a dash
```
variable-name
```
