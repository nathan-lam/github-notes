# Definition

A shallow copy is a new variable that points to the original variable.
- Changing the shallow changes the original
- Faster to create


A deep copy is a new variable that copies the values of the original variable.
- A deep copy is independent from the original
- Can take longer to create

# Example
```python
x = 1
y = x + 1

```
