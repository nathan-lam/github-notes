# Application
To evaluate if the a random variable is statistically equivalent to a guess
# Hypothesis

$$H_{0}: \mu = c$$
$$H_{A} : \mu \neq c$$

# General Assumptions
- Independent samples
- Rank-able data
- No ties
- Not very skewed

# Variations

| Test                                         | Test Statistic | Assumptions |
| -------------------------------------------- | -------------- | ----------- |
| Mann-Whitney U Test (Wilcoxon Rank-Sum Test) |                |             |
| Wilcoxon Signed-Rank Test                                             |                |             |


# Related
