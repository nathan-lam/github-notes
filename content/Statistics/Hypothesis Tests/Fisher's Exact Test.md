# Application
Nonparametric test of independence between two variables

Testing a 2x2 contingency table if 2 groups are the same

|   | Group A | Group B |
| --- | ------- | ------- |
| Yes | a       | b       |
| No  | c       | d       |    |         |         |

# Hypothesis
H_0: Group A and Group B have the same distribution
H_A: Group A and Group B have the different distributions
