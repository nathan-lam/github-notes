A method of quantifying how confidence we are obtaining the true value
Typically used to gauge the possible values the true value could be

# Definition
Given a 95% interval
$$
P(lower < \theta < upper) = 0.95\\
$$
We would write $[lower, upper]$ as the 95% Confidence Interval
