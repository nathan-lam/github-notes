# Definition
Given n [[Independent and Identically Distributed]] samples, a random sum approaches a [[Normal]] distribution.

More accurately: 
$$ 
\text{Given }X_{i} \text{ iid } \forall i\in{1,\dots,n} \text{ and }\bar{X}_n=\frac{1}{n}\sum^n_{i=1}\limits X_{i} \text{, then } \frac{(\bar{X}_n-\mu)}{\sigma}\rightarrow Normal(0,1) \text{ as } n\rightarrow \infty



$$

# Applications
Rule of thumb - sample size > 30 means the the CLT will kick into effect
