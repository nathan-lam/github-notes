# Definition
The variance of an estimator is bounded by the inverse [[Fisher Information]]

$$var(\hat{\theta}) \geq \frac{1}{I(\theta)}$$
$\hat{\theta}$ is a random variable that estimates the true value $\theta$ 

This means it is impossible to eliminate all uncertainty about an estimator, but it can be a goal to achieve the lowest variance estimator.

# Related
- An estimator that equals the lower bound is called efficient
