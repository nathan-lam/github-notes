# Definition

## Probability Density Function
$$f_X(x|\mu, \sigma) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{1}{2}(\frac{x-\mu}{\sigma})^2}$$

- This is the resulting distribution for the [[Central Limit Theorem]]
