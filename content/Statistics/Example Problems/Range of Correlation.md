# Question
Suppose you have N [[Random Variable|random variables]] where any pairwise combination of random variables have the same correlation.
Find the range of the correlation


# Answer

## Naive Guess
The naive guess is that the range will be \[-1,1]   as that is the defined range of correlation.

The correlation matrix will be composed of two parts:
- $corr(X_i, X_i)$
	- This is 1 as it is the correlation with itself
- $corr(X_i, X_j) = \rho$
	- This is given that all random variables have the same correlation ($\rho$)
