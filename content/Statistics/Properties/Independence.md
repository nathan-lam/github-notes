# Definition
A property that one [[Random Variable]] does not affect another.

Explicitly, this is $P(X|Y) = \frac{P(X \& Y)}{P(Y)} = \frac{P(X)P(Y)}{P(Y)} P(X), independence \implies P(X \& Y) = P(X)P(Y)$
