# Architectures
Considers the nature of the input into consideration

## [[Perceptron]]
The most basic neural network, input to output, no hidden layers

The following models fall under this definition
- Linear Regression - linear activation
- Logistic Regression - sigmoid activation

## [[Generative Adversarial Network]]
A system of two models competing with each other
Generator vs Discriminator

## [[Recurrent Neural Network]]
Best for data that relate to the past
- Words
- Time Series
## [[Convolutional Neural Network]]
Best for image data
