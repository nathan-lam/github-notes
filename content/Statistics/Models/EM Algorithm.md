# Definition
A model fitting algorithm to find the parameters that best fit the data.

Expectation-Maximization Algorithm

An algorithm that aims to model data by finding the parameters that maximizes the likelihood of the observed data

There are two steps
1. Calculate Expectation with initial parameters
2. Update the parameters that maximizes the expectation
3. Repeat
