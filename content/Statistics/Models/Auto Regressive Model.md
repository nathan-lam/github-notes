# Definition
A model that relies on past terms.

$$X_{n}=c_{0}+c_{1}X_{n-1} + c_{2}X_{n-2}$$
Future values are a linear combination of past values

An auto regressive model (AR) is defined by how many past terms are used.
- $AR(2)  \implies X_n = c_0 + c_1 X_{n-1} + c_2 X_{n-2}$


# Notes
Impulses can be felt infinitely far away as they decay in time based on the coefficients, but never truly go away.
