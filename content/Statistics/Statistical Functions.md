# Probability Distribution Function
$P(X=x)$, likelihood (height of the pdf)
PDF: z-score -> probability

# Cumulative Density Function
$P(X\leq x)$, area to the left of a point in the PDF

CDF: z-score -> probability
pnorm: 0 -> 0.5
# Inverse CDF

Inverse CDF: quantile -> z-score
qnorm: 0.5 -> 0
