# Definition
A technique that converts a categorical variable into binary values.

If a categorical variable has multiple outcomes, this this gets split into many binary columns.


# Related
- Do not include all n categories and an intercept term in a [[Linear Model|linear model]]
	- it becomes redundant
	- the intercept term encodes the last category and becomes the point of comparison the categorical coefficients have.
