# Data Safety
- Keep up to date software
- Maintain safety practices
- Use passwords


# Backups
- 3 backups
- 2 different medium
- 1 offsite backup

do not use USB flash drives as backups
- easy to lose
- not encrypted
- easily corruptable
- ONLY FOR TRANSFERRING FILES

keep maintaining backups
- update regularly
- test if file integrity is maintained
