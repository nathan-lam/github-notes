# Definition
An argument for a creator.

```
A person walking through the woods can recognize a watch as not natural because it was so delicately designed that a watch maker must exist to have designed it.
```

Do note that there is no description of the creator. this argument is as valid for a benevolent creator as a malevolent creator.

# Issues

## Argument from ignorance

A common response is to say something similar to:
```
The human body was designed so complexly, so carefully, that this was intelligently put together by a creator.
```

This might be applied to systems of complex interactions such as the 


The essence of the argument is that if feels overwhelmingly complex that it could never have occurred naturally.
- This is essentially saying, this is so complex that I dont understand it and therefore it is not natural.

Saying "I dont know" is not evidence for a creator, only that no reasonable explanation exists.
- Saying God can explain what we dont know is no better than saying a wizard did it.


**At the very least, who are we to judge what is complex or not, as the method of existence does not care for what we think.**

## Not falsifiable (yet)
How can you empirically distinguish if, for example, the human body was intelligently designed?

In order to test this, we have to be capable of being creators ourselves.

## False Equivalence
The statement is often explained as part of an analogy, commonly a pocket watch, but this may not be an equivalent comparison.

Ex.
It needs to be proven the the complexities of a watch is of a similar type of complexity as a human body.
