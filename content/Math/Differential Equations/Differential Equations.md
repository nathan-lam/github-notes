# Definition
A subfield of math that studies methods of solving differential equations.


There are [[Ordinary Differential Equations]] (dealing with single variable functions) and [[Partial Differential Equations]] (dealing with multi variable functions)

# Example

An example is a basic
$$
y'' + y' + y = 0
$$
