# Definition

Numbers that can be represented as $a + b\epsilon, a,b \in \mathbb{R^2}, \epsilon^2=0, \epsilon\neq0$

$\epsilon$ is an infinitesimal that acts like zero but is not zero. A ratio with the denominator of solely $\epsilon$ is equivalent to a division by zero error
