# Definition
The component of a vector onto another vector.


Projecting a vector $\vec{x}$ onto vector $\vec{y}$ is shown as 
$$proj_y x:=\frac{\langle \vec{x},\vec{y}\rangle}{\langle \vec{x},\vec{x}\rangle}\vec{y}$$
The [[Inner Product]] is used to measure how much similar $\vec{x}$ is to $\vec{y}$ and then scaled back
