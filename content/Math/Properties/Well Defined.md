# Definition
An element is well defined if two elements of the **same** class give the same result under a relation.

The relation can by anything.



# Example

## Addition of Rational Numbers
It can be shown that two equivalent rationals can give the same result when adding the same number
- 1/2 + 1/3 = 2/4 + 1/3
