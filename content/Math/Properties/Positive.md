# Definition
A property of an element to be greater than zero.


This implies there exists an [[ordering]] of the elements, 0 being one of the elements.



# Examples


## Natural Numbers
A natural is positive if it is not zero


## [[Integer Numbers]]
An integer is positive if it is in the Naturals except zero

## [[Rational Numbers]]
A rational number, $\frac{p}{q}$, is positive if $pq > 0$
