# Definition
A property of an operator if every input has a unique output.


When graphing algebraic functions, this is the horizontal line test.
- A function is not one-to-one if multiple input goes to the same output
	- f(a) = c = f(b)
- This means that there is a **horizontal line** that passes through more than 1 point in the function.


# Example
- $f(x) = x^2$
	- Not one to one because $f(x)=1$ can have $x=\pm1$
	- f(x)=1 does not have a unique input
- $f(x)=log(x)$
	- Is one-to-one because every input has a unique output
