# Definition
A property of an operator where every input has a valid output.


The test is whether the output continuously ranges $(-\infty, \infty)$
- This means every input can map to any output value

# Examples
- $f(x)=x^2$
	- Is not onto for $\mathbb{R} \rightarrow \mathbb{R}$ because there is no real number that maps to -1
- $f(x)=(x+1)x(x-1)$
	- Is onto because every input maps to $(-\infty, \infty)$
	- Note that this is not one to one because multiple inputs map to f(x)=0
- $f(x)=log(x)$
	- Is onto because every valid input maps to $(-\infty, \infty)$
	- Note that the input domain does not need to span infinitely
