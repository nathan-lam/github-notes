# Definition
An analytic continuation of the factorial function
$$
\Gamma(z)=\int^\infty_0 t^{z-1}e^{-t}dt
$$



# Properties
1. $\Gamma(z+1)=z\Gamma(z)$
2. $\Gamma(1)=1$
3. The Gamma function always converges
