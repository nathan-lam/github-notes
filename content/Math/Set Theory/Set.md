# Definition
A collection of objects. They can be anything like numbers, colors, moods, or other sets.

The notation typically follows $X=\{x|F(x)\}$
- In english: The set of $X$ has elements $x$ defined by condition $F(x)$

# Examples

$$
\begin{aligned}
A &= \{1, z, 65, sd\}, &\text{Set of alphanumerics}\\
B &= \{red, blue, orange\}, &\text{Set of colors}\\
C &= \{\}, &\text{Null set}\\
D &= \{x | -\infty < x < \infty\}, &\text{Any number between pos/neg infinity = the real numbers}
\end{aligned}
$$
