# Definition
A sequence that derives the next term based on the previous terms.
Given an initial term, this generates a sequence of numbers.


The Fibonacci Numbers is a famous example where the relation is $F_n = F_{n-1}+F_{n-2}$

# Notes

## Constant Coefficients
If coefficients are constant, then [[Linear Algebra]] can be used to calculate a closed form solution.


## Linear Models
A [[Linear Regression]] can be fit using a recursive relation. This effectively becomes an [[Auto Regressive Model]].
