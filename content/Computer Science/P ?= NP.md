# Definition
An unsolved problem whether hard problems to solve always have a quick algorithm to solve it.

A class P problem is a problem that can be solve in [[polynomial time]], $O(n^a)$. These are problems that can be quickly solved.


A class NP problem are problems that are hard to solve but quick to verify (Can be verified in polynomial time)


It is likely that P != NP but the consequence of P=NP would break many protections and development in life.
