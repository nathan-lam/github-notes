

A server is just someone elses computer, but this computer doesn't have to be owned by a big tech company.


# Things needed
- A spare computer
	- An unused desktop/laptop/single board computers
	- this should be able to connect to the internet
- (optional) ethernet connection
- (optional) UPS to maintain power during powerouts



# Safety
Connecting to a computer on your same network is trivial, so if you want to connect over the internet, there are precautions needed

1. Password protect services
2. bot protection from spamming trying to connect
